# FEMORA-One

FEMORA stands for Flow-based Electrolysis Membrane-less Open-source Reactor Architecture.

## Overview

FEMORA is an open-source millifluidic electrolysis reactor framework intended for applications across biomedicine, energy generation, and manufacturing. The core idea is to provide a scalable, cost-effective, and efficient architecture for electrolysis processes using millifluidics in a membrane-less system.

## Project Aim

- Develop a reusable reactor architecture for electrolysis work.
- Make the design adaptable across scales and applications.
- Support future projects such as [[hypochlorous-acid-generation]].
- Keep the design compatible with modular open-source automation hardware.

## Integration with BREAD

The original project concept called for FEMORA to use or adapt BREAD slices.

BREAD is described in the source stub as the Broadly Reconfigurable and Expandable Automation Device: a modular open-source data acquisition and automation framework. FEMORA should either reuse general BREAD slices or motivate specialized slices where electrolysis work needs new hardware.

## Intended Repository Structure

The original stub planned these work areas:

- `Designs`: CAD files, schematics, and design documents.
- `Firmware`: controller and interface source code.
- `Documentation`: setup guides and usage instructions.
- `BREAD-Integration`: files and instructions for BREAD slice integration.
